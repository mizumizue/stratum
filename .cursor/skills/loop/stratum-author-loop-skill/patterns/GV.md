# GV — Gen–Verify

出典: Andrej Karpathy（Software 3.0 / autoresearch）。生成と検証を分離し、検証器を leash する。

## 1周

1. 現状と制約を読む  
2. 小さな変更を1つ提案し適用する  
3. **Verifier**（数値・テスト・固定コマンド）を実行する  
4. 改善なら keep、悪化／失敗なら discard（戻す）  
5. Stop まで繰り返す  

## kernel への写像

| 柱 | 典型 |
|----|------|
| Verifier | エージェントが編集できない評価コマンド／メトリクス |
| State | 実験ログ、ベスト成果物、現行コード |
| Stop | 目標スコア、時間／回数上限、改善停滞 |
| Leash | 評価スクリプト・データ・採点定義は編集禁止 |

## 向く目的

比較可能なスコアや自動判定がある探索・チューニング。
