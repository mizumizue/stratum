# GRILL — 意思決定ツリーを潰すインタビュー

出典: mattpocock/skills の `/grilling`。検証器＝ユーザーとの共有理解。

## 1周

1. 未解決の枝を1つ選ぶ  
2. 質問を1つだけする（推奨回答付き）  
3. 回答を待って枝を閉じる  
4. 全枝が閉じ、ユーザーが共有理解を確認するまで繰り返す  
5. 確認後に初めて実行・生成へ進む  

## kernel への写像

| 柱 | 典型 |
|----|------|
| Verifier | 「この理解でよいか」のユーザー確認。事実は自分で調べ、決定だけ聞く |
| State | 確定事項表、未解決枝リスト |
| Stop | ユーザーが共有理解を承認したとき |
| Leash | 質問をまとめ打ちしない。承認前に実装・ファイル生成へ進まない |

## 向く目的

要件・設計・方針がまだ割れているとき。他型の前段にも使える。
