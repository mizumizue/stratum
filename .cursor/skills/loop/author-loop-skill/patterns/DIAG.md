# DIAG — Red-loop-first diagnose

出典: mattpocock/skills の `/diagnosing-bugs`。仮説の前にタイトな赤シグナルを作る。

## 1周（フェーズ付き）

1. **この症状で赤になる**高速・決定的・エージェント実行可能なコマンドを作る  
2. 再現し、まだ赤のまま最小化する  
3. 仮説を出し、1変数ずつ検証する  
4. 正しいシームに回帰テストを書いてから直す  
5. 元のループが緑になるまで確認し、計装を外す  

## kernel への写像

| 柱 | 典型 |
|----|------|
| Verifier | 症状をアサートする再現コマンド |
| State | 再現手順、仮説リスト、計装、回帰テスト |
| Stop | 症状が消え、回帰が緑、計装除去 |
| Leash | 赤コマンドなしに「原因推定だけ」で修正フェーズへ進まない |

## 向く目的

バグ・性能退行・「壊れている」報告。
