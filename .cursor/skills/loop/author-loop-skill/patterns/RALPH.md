# RALPH — 同一指示の反復ループ

出典: Geoffrey Huntley の Ralph Wiggum（`while` ループ）。状態はディスク、コンテキストは周ごとに新鮮でもよい。

## 1周

1. 固定の指示（PROMPT／計画）を読む  
2. **今いちばん重要な1こと**だけ進める  
3. Verifier（テスト・lint・完了条件）を走らせる  
4. 成果をファイル／git に残す  
5. 完了約束（completion promise）か上限まで外から繰り返す  

## kernel への写像

| 柱 | 典型 |
|----|------|
| Verifier | テスト／ビルド／「DONE」条件の機械的確認 |
| State | 計画ファイル、仕様、進捗メモ、git 履歴 |
| Stop | 完了フレーズ、max iterations、全タスク消化 |
| Leash | 1周1タスク。指示ファイルを周ごとに勝手に書き換えない（人間が調律） |

## 向く目的

仕様と検証が揃ったうえで、長時間・反復で進める実装。
